# New Air Quality Data Reporting Guide – Reportnet 3 available

*Published: 2026-07-17*  

We are pleased to inform you that EEA’s AQ data reporting guide for Reportnet 3 is now available here: <https://eeadata.github.io/AQ.Documentation.ReportingGuide/>. We recommend bookmarking this link for your convenience and ease of access in the future.

The guide provides detailed descriptions of reporting tables and elements and is intended to support your future data submissions via Reportnet 3 following the new reporting schema.

As part of the transition to Reportnet 3, the guide has been developed in a new web-based format, replacing the previous Excel-based documentation. This new format will allow for more efficient updates and easier navigation in the future.

We kindly encourage you to review the new reporting guide and familiarise yourselves with the updated reporting schema as this will help ensure a smooth preparation for upcoming data submissions via Reportnet 3.

Should you have any questions, please do not hesitate to contact us using the AQ IPR helpdesk email: [aqipr.helpdesk@eionet.europa.eu](mailto:aqipr.helpdesk@eionet.europa.eu).
