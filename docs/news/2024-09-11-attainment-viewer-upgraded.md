# Attainment viewer upgraded

*Published: 2024-09-11*  
*Source: [https://aqportal.discomap.eea.europa.eu/2024/09/11/attainment-viewer-upgraded/](https://aqportal.discomap.eea.europa.eu/2024/09/11/attainment-viewer-upgraded/)*

An upgraded version of the attainment viewer is now online under the section ‘*Compliance status*‘.

New features are:

– display difference between EAA and G + associated filter

– access to G envelope

– link to google map in windows ‘associated SPOs’ and ‘SPOs map’

– number of zones displayed in title of main table

– filter on source for adjustment

– the column Source for adjustment is only filled in when filter Type of exceedance is set to adjustment

– tooltip in SPO graph displaying data coverage

– country replaced by country ISO in tables

– info page updated
