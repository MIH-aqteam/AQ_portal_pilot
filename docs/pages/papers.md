# PaPeRS

## Plans and Programmes e-Reporting System

The **Plans and Programmes e-Reporting System (PaPeRS)** supports air quality experts in preparing XML files for reporting **Air Quality Plans and Programmes (dataflows H to K)** under the **Reportnet 2 Air Quality e-Reporting system**.

The application was developed by the European Commission's Joint Research Centre (JRC) in Ispra and is hosted by the European Environment Agency (EEA).

```{note}
PaPeRS is a tool for preparing XML files for reporting Air Quality Plans and Programmes. Access to the application does **not** in itself authorise users to submit data to the EEA.
```

## Access to PaPeRS

The centrally hosted EEA version of PaPeRS is available at:

- [PaPeRS application](http://papers.eionet.europa.eu/)

Users are redirected to the European Commission authentication service (EU Login) before accessing the application.

To use PaPeRS:

1. Sign in using your professional EU Login account.
2. If you do not yet have an account, follow the registration procedure from the login page.
3. For most users, the appropriate authentication domain is **External**.
4. Ensure that you have been granted access to the application by your national administrator.

For authentication problems, consult:

- [EU Login Help](https://webgate.ec.europa.eu/cas/help.html)

```{important}
A valid EU Login account alone does not provide access to PaPeRS. Access rights must first be granted by your national administrator.
```

## Submission of XML files

XML files prepared with PaPeRS must be submitted by authorised national representatives through the EEA Central Data Repository (CDR).

- [Central Data Repository (CDR)](http://cdr.eionet.europa.eu/)

For information on access to the CDR, see:

- [Access to CDR](access-to-cdr.md)

## Standalone version

Reporting authorities wishing to deploy PaPeRS within their own infrastructure may use the standalone version.

The source code is available from the EEA GitHub repository:

- [PaPeRS source code](https://github.com/eea/aqr-public)
