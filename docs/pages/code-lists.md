# Code Lists

Code lists define the controlled vocabularies used for air quality reporting. They ensure that countries use consistent and unambiguous values when reporting information on monitoring, assessment, observations, exceedances, plans and measures.

Most code lists are maintained in the **Eionet Data Dictionary**. Selecting a code list below opens the corresponding vocabulary in a new browser tab.

```{note}
The catalogue includes code lists used for **Reportnet 2**, together with newer vocabularies introduced to support the evolving air quality reporting framework.
```
